# Последняя смена — сохранённые версии

Репозиторий: https://github.com/Horider/-The-Last-Shift

Для игры по публичной ссылке включите в репозитории GitHub **Settings → Pages → Deploy from a branch → main → / (root)**. После успешной публикации меню будет доступно по адресу `https://horider.github.io/-The-Last-Shift/`, а последняя версия — `https://horider.github.io/-The-Last-Shift/releases/0.8/index.html`. Сохранение кода в репозитории само по себе не включает Pages. Файл `.nojekyll` подготовлен для статической публикации.

Дважды нажмите `Запустить игру.cmd`. Скрипт запускает локальный сервер в фоне и открывает меню версий в обычном браузере по HTTP, обычно `http://127.0.0.1:4174/`. Выберите версию. Повторный запуск использует уже работающий сервер. Он продолжает работать после завершения чата. Интернет не требуется.

Прямое открытие `file://` во встроенном браузере в этой сессии вызывает сбой; используйте HTTP-запуск. Каждая сохранённая сборка остаётся самостоятельным HTML со встроенными изображениями. Оригинальные сборки не изменены.

- `releases/0.3/index.html`: оригинальная сохранённая 0.3, четыре комнаты и десять вещей.
- `releases/0.1-restored/index.html`: восстановленная первоначальная игра с управляемым 2D-роботом. Движение: WASD, стрелки или нажатие на пол; нажатие на предмет — подойти и осмотреть; E — действие, F — осмотр, Q — положить. Десять предметов, четыре поручения, пар, рейтинг и спасение ЛУЧа. Исходный код найден в сохранённой истории создания; HTML собран заново, поэтому это не побайтовая копия первоначального экспорта. Исходники: `src/robot-2d`.
- `releases/0.4-restored/index.html`: восстановленный интерфейс 0.4 с 22 вещами, экраном ЛУЧа и тремя нижними кнопками. Оригинальный HTML 0.4 был ошибочно перезаписан версией 0.5, поэтому эта сборка восстановлена по исходникам и не является точной архивной копией.
- `releases/0.5/index.html`: оригинальная сохранённая 0.5 с ящиком, иконкой журнала и RU/EN.
- `releases/0.6/index.html`: комнаты во весь экран, камера с зумом до 22% и перемещением пальцем, надписи прямо на дверях, отдельный нарисованный экран ящика. Нажмите на ящик в шлюзе, затем выберите действие внутри; собранные вещи можно осмотреть.
- `releases/0.7/index.html`: исправление растянутых фонов 0.6. Для шлюза, ЛУЧа и ящика дорисованы широкие и вертикальные варианты окружения. Изображения, зоны нажатия и надписи используют один масштаб с сохранением пропорций. На телефоне и на широком экране выбирается подходящий рисунок. Размеры мастеров: 1774×887 и 852×1846; промпты и происхождение перечислены в `src/ART-NOTES.txt`.

- `releases/0.8/index.html`: собственный кабинет ЛУЧа с отдельной дверью в шлюзе. Внутри кабинет со столом, креслом, архивом и монитором; здесь получают задания и уточнения. Широкий и телефонный варианты сохраняют пропорции.

Оригинальные HTML ранних 0.1/0.2 не найдены среди сохранённых сборок. Для 0.1 удалось восстановить исходный код из истории создания. Отдельная архивная сборка 0.2 пока отсутствует.

Текущие исходники 0.8 находятся в `src/dist`, тесты — в `src/tests`. Исходная папка предыдущего чата не изменена. Здесь нет ключей API или облачной регистрации.

После будущих изменений сохраняйте НОВУЮ версию, например:

```powershell
node tools/export-release.cjs 0.9 "Описание изменений"
```

Экспорт откажется перезаписывать уже существующую версию. Меню обновится автоматически. Проверка сохранённых сборок: `node tools/check-releases.cjs`.

Служебные данные сервера находятся в `.local/server.json`, журналы — `.local/server.log` и `.local/server-error.log`. Если порт 4174 занят другим сервисом, сервер выбирает свободный порт, а скрипт открывает правильный адрес автоматически. Сервер принимает соединения только с этого компьютера.
